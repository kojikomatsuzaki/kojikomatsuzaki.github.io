# 小松崎浩司のGitHub

公開サイト：<https://kojikomatsuzaki.github.io/>

研究・デジタルアーカイブ・オープンデータ・Webツールなどの公開リポジトリ12件をまとめたトップページです。代表的な3件への入口を先頭に置き、残りを含む全件の一覧を表示します。サイト自体のリポジトリは一覧の件数に含めません。

## 構成

| ファイル | 役割 |
| --- | --- |
| projects.js | プロジェクト名・キャプション・公開先・利用条件・更新日の正本。代表コンテンツの `featured` と公開区分 `status` も管理 |
| app.js | 正本データから代表コンテンツと全件のカードを表示 |
| styles.css | 丸ゴシック・ピンク／ラベンダー／ミントの配色とレイアウト |
| index.html | ページ構造、サイト全体の更新日、利用条件へのリンク |
| LICENSE | このサイト自体の利用条件 |

フレームワーク・外部フォント・閲覧時のGitHub APIは使用しません。API制限や通信失敗で一覧が消えたり、更新日が空欄になることを避けるため、確認した情報を projects.js に保存しています。

公式・非公式の表示はプロジェクトごとに設定します。日立市天気相談所の観測データは非公式アーカイブであり、新荘音頭とインターバルタイマーにはその表記を適用しません。各プロジェクトのヘッダー・フッターは独立して管理します。

## 更新方法

1. projects.js の配列にプロジェクトを追加、または既存項目を修正します。
2. repo はリポジトリ名、name は表示名、caption は簡単な説明です。
3. page は実際に開ける公開サイトがある場合だけ指定します。空のリポジトリは readme: false にします。
4. updated はGitHubの pushed_at（最終プッシュ日時）を記録します。表示日は日本時間です。資料そのものの更新日とは異なる場合があります。
5. license はLICENSE・README・出典の条件を確認して記述します。未指定の場合に利用許諾を推測してはいけません。
6. index.html の一覧全体の最終更新日を更新します。
7. ローカルで表示を確認し、main に反映します。

新しいリポジトリは自動では追加されません。説明や公開範囲を確認してから手動で加える運用です。

## 公開方法

GitHub Pages の公開元を main ブランチのルート（/）に設定します。.nojekyll を置き、HTML・CSS・JavaScriptをそのまま配信します。既存の各プロジェクトのPages設定は変更しません。
